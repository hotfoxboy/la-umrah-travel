# Logótipo oficial

Arte original fornecida pelo utilizador: `Logo Umrah.png`, 5284 × 2906 px.

As versões WebP de 400 e 800 px removem apenas as margens brancas exteriores e comprimem o ficheiro para utilização no cabeçalho e no rodapé. O desenho, as cores, as letras e as proporções são preservados. O original não foi alterado.

O pictograma da Kaaba usado como favicon é um recurso separado (`app/icon.svg`).
